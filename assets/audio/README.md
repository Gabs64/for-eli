# 🎵 Custom Audio Assets

You can optionally place your custom audio files in this directory:

- `background-music.mp3`: Your chosen background song (instrumental, lofi, acoustic, or music box).
- `paper-sound.mp3`: Custom paper rustling sound effect.

### Note:
If you do not add any MP3 files here, the application **automatically synthesizes** soothing ambient Rhodes chords and paper sounds via the browser's built-in Web Audio API!
